A deterministic, offline, stdlib-only program that writes one line — the funniest error message a kitchen toaster would show its owner — to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

The program writes a fixed 51-character line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt` when set). No randomness, no clock, no network — every run produces byte-identical output.
